1. Users Table

Core Application | User Accounts, Sellers, Buyers, Admins
Keys Field Name Data Type Description
PK id BIGINT Auto-incrementing unique identifier
name VARCHAR(255) User's full name
UNIQUE email VARCHAR(255) User's email address for login
email_change_token VARCHAR(255) Token for email change verification (nullable)
email_change_new_email VARCHAR(255) New email address pending verification (nullable)
email_change_expires_at TIMESTAMP When email change token expires (nullable)
role ENUM('seller','buyer','admin') User role. Default: 'seller'
email_verified_at TIMESTAMP Timestamp when email was verified (nullable)
password VARCHAR(255) Hashed password for authentication
remember_token VARCHAR(100) Token for "remember me" functionality (nullable)
is_verified BOOLEAN Verification status for buyers/recyclers. Default: false
business_name VARCHAR(255) Name of the business for sellers/recyclers (nullable)
business_description TEXT Description of business operations (nullable)
phone VARCHAR(20) Contact phone number (nullable)
total_impact_score DECIMAL(10,2) Cumulative environmental impact score. Default: 0
items_processed INT Total number of e-waste items processed. Default: 0
total_weight_diverted DECIMAL(10,2) Total weight diverted from landfill in kg. Default: 0
total_co2_saved DECIMAL(10,2) Total CO2 emissions saved in kg. Default: 0
google_id VARCHAR(255) Google OAuth provider ID (nullable)
oauth_provider VARCHAR(50) OAuth provider name: 'google', 'github', etc. (nullable)
created_at TIMESTAMP Account creation timestamp
updated_at TIMESTAMP Last account update timestamp

3. Listings Table

Core Business | E-Waste Items Posted for Sale/Donation
Keys Field Name Data Type Description
PK id BIGINT Auto-incrementing unique identifier
FK user_id BIGINT Seller's user ID. References users(id). CASCADE on delete

status ENUM('pending','available','matched','in_transit','delivered','processed') Listing status. Default: 'pending'

delivered_at TIMESTAMP When the item was delivered (nullable)
processed_at TIMESTAMP When the item was processed (nullable)
carbon_footprint DECIMAL(10,2) Carbon footprint in kg CO2 (nullable)

SOFT DEL deleted_at TIMESTAMP Soft delete timestamp (nullable)
